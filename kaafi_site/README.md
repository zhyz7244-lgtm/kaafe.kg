# KAAFI — сайт кофейни на Django

Заказ со стола по QR-коду, уведомления админу, управление меню/скидками/отзывами через админ-панель.

## Запуск

```
pip install -r requirements.txt
python manage.py migrate
python manage.py seed          # меню, 10 столов
# затем откройте http://127.0.0.1:8000/staff/setup/ и создайте администратора
python manage.py runserver
```

Сайт: http://127.0.0.1:8000 · Админка: http://127.0.0.1:8000/admin/

## Как это работает

- **Столы.** В админке → «Столы» у каждого стола свой QR (ссылка вида `/t/<случайный-код>/`).
  «Распечатать QR» / кнопка на главной админки печатает карточки для всех столов.
  Гость сканирует QR → открывается меню, стол уже выбран → оформляет заказ.
  Если открыть сайт без QR, гость выбирает номер стола вручную.
- **Уведомления админу.**
  1. Страница **/staff/orders/** (кнопка на главной админки): новые заказы появляются сами,
     со звуком, с номером стола и составом. Там же статусы: принят → выдан / отменён.
     Держите её открытой на планшете/телефоне на баре (нажмите «Включить звук» один раз).
  2. Telegram (по желанию), 3 шага:
     1. Создайте бота у @BotFather (`/newbot`), скопируйте токен.
     2. Скопируйте `.env.example` в `.env`, впишите `TELEGRAM_BOT_TOKEN=...`, напишите боту любое сообщение.
     3. `python manage.py telegram_setup` — найдёт ваш chat id (впишите его в `.env`);
        запустите команду ещё раз — придёт тестовое сообщение. Дальше каждый заказ приходит в Telegram.
  Если Telegram недоступен, заказ всё равно оформляется — уведомление его не блокирует.
- **Фото товаров.** Пока фото нет, на карточке рисуется иллюстрация напитка (чашка или айс-стакан).
  Загрузили фото в админке — оно сразу заменяет иллюстрацию.
- **Товары.** Админка → «Товары»: название, объём, цена, фото, описание, наличие.
  Цену, скидку и наличие можно менять прямо в списке.
- **Скидки.** В товаре поле «Скидка, %» (и необязательно «действует до»). На сайте — бейдж
  «−X%» и зачёркнутая старая цена. Итог заказа всегда считается на сервере.
- **Отзывы.** Гости оставляют отзыв с оценкой и до 4 фото. Отзыв появляется на сайте
  после одобрения: админка → «Отзывы» → галочка «Опубликован».

## Подключение уведомлений (проще всего)

Админка → «Уведомления» (`/staff/notifications/`): пошаговая страница с кнопками «Найти мой chat id»,
«Сохранить», «Отправить тест» для Telegram и WhatsApp. Настройки сохраняются в `.env` сами (менять их
может только главный администратор). Приходят: новый заказ (стол, состав, клиент), заказ книги, новый отзыв.

Страница **/staff/orders/** («Заказы») — рабочее место бариста: новые заказы и заказы книг появляются сами
со звуком, статусы меняются кнопками, а гость на сайте видит, как заказ «Принят → Готовится → Готово».

## Статистика, книги, клиенты и бонусы

- **Статистика** — Админка → «Статистика» (`/staff/stats/`): выручка и заказы этого месяца к прошлому и этого
  года к прошлому (с процентом); выбор периода (год и месяц) с разбивкой **по разделам** — кофе, холодный кофе,
  напитки, мохито, еда и книги: сколько продано, заказов, выручка, доля; **топ позиций меню** и **топ книг**;
  средний чек кофейни и лучший раздел; график по месяцам (кофейня и книги разными цветами, клик по месяцу
  открывает подробности) и таблица по годам. Отменённые заказы не учитываются.
- **Напитки, мохито, еда** — это обычные категории: Админка → «Категории» (уже созданы «Напитки», «Мохито»,
  «Еда»), затем «Товары» → фото, цена, описание. Категория без товаров на сайте не показывается.
- **Книги (каталог на ~300 штук)** — на сайте раздел «Книги» (`/books/`): поиск по названию/автору/коду,
  жанры, сортировка, страницы по 24, страница каждой книги с фото и описанием, скидка (если указана старая цена).
  Покупатель складывает в корзину несколько книг и оформляет заказ: **доставка** (страна, город, адрес) или
  **самовывоз** из кофейни; имя и адрес запоминаются для следующего заказа. Стоимость доставки менеджер
  подтверждает по телефону. Оплата при получении. За книги бонусы не начисляются (только за кофе).
  - Добавить книги: Админка → «Книги». Для сотен книг — страница **/staff/books/import/** (кнопка «Книги»
    в панели): 1) загрузите таблицу CSV (шаблон скачивается там же; повторная загрузка обновляет, а не
    дублирует); 2) загрузите **фото пачкой** — файл `B-001.jpg` встанет к книге с кодом `B-001`, либо
    `Название книги.jpg` — к книге с таким названием. Фильтр «Без фото» в админке покажет, чего не хватает.
  - Заказы книг приходят в Telegram/WhatsApp и на страницу «Заказы» (со звуком); статусы меняются кнопками.
- **WhatsApp-уведомления** — в `.env`: `WHATSAPP_PHONE` и `CALLMEBOT_APIKEY` (бесплатный шлюз CallMeBot).
- **Постоянные гости** — страница `/account/`: регистрация по телефону и паролю, профиль с QR-кодом
  (`KAAFI-123456`), историей бонусов и заказов. Заказать можно и без регистрации.
- **Бонусы 1% (только за кофе)** — начисляются автоматически, когда заказ зарегистрированного гостя получает статус «Выдан»
  (один раз за заказ; отменённые не дают). Касса — `/staff/customers/` (кнопка в админке): поиск по QR/коду/
  телефону/имени, ручное начисление и списание (баланс не уходит в минус). Сканер QR работает в Chrome/Edge.
- **QR гостя → касса.** В QR гостя зашита ссылка на кассу. Бариста наводит камеру телефона (или кнопку
  «Сканировать QR») — карточка гостя открывается сразу; вводит сумму чека за кофе, нажимает «Начислить 1%».
- **Регистрация гостя на кассе** — `/staff/customers/` → «Зарегистрировать нового гостя»: имя и телефон,
  пароль задайте или получите временный (гость сменит его в профиле → «Настройки профиля»).
- **Аккаунты персонала** — `/staff/account/`: смена логина и пароля, добавление сотрудников (бариста видят
  заказы, клиентов, книги, статистику — но не настройки и аккаунты). **Первый запуск:** откройте
  `http://127.0.0.1:8000/staff/setup/` и создайте администратора со своим логином и паролем
  (работает только пока администратора нет и только с этого компьютера).
- **Забыл пароль** — Админка → «Клиенты» → выбрать клиента → действие «Сбросить пароль»: появится
  временный пароль, передайте его клиенту.

## Перед выкладкой в интернет

Настройки задаются в файле `.env` (образец — `.env.example`) или переменными окружения.
Страница печати QR-кодов предупредит, если в них ещё локальный адрес.

| Переменная | Значение |
|---|---|
| `DJANGO_DEBUG` | `0` |
| `DJANGO_SECRET_KEY` | длинная случайная строка |
| `DJANGO_ALLOWED_HOSTS` | `kaafi.kg,www.kaafi.kg` |
| `DJANGO_CSRF_TRUSTED_ORIGINS` | `https://kaafi.kg` |
| `SITE_URL` | `https://kaafi.kg` — **зашивается в QR-коды**, печатать их надо после установки |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | уведомления в Telegram |

Для продакшена: `gunicorn config.wsgi`, `python manage.py collectstatic`, а `/static/` и `/media/`
(загруженные фото) отдавать через nginx. Фото лежат в папке `media/` — включите её в бэкапы.
